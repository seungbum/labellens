# Cloud workspace measurement, 2026-10-21

Directory, endpoint probe and collection log from a first run in a cloud workspace on 2026-10-21.
Its egress proxy refused many label streams (81 of 493 collection attempts failed at the proxy), so the
same day's run on a GitHub-hosted runner (`data/actions_20261021/`) was used instead. Neither run is used
in the current paper, which reports the 2026-10-28 measurement. No raw labels are kept.
